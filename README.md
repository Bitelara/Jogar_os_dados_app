# Jogada_de_dados

Aplicativo desenvolvido como exercício para a faculdade, utilizando a plataforma **MIT App Inventor**.

## Descrição

Ao clicar em um dos botões disponíveis - **D4, D6, D8, D10, D12, D20 e D100** - o app gera um número inteiro aleátorio correspondente à quantidade de lados do dado selecionado.

## Tecnologias utilizadas

- MIT App Inventor 2

## Observações

Este aplicativo foi desenvolvido como parte de um exercício prático, com fins educacionais.
